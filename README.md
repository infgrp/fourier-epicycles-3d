# 3D 푸리에 에피사이클

회전하는 원 수백 개의 벡터 합으로 3차원 폐곡선, 글자, 인물 윤곽선을 그리는 Babylon.js 시각화입니다.
원(주파수 성분)의 개수 N이 늘어날수록 모양이 정교해지는 과정을 보여 줍니다.

`index.html` 하나로 동작합니다. 백엔드는 없고, Babylon.js를 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 원리
- 곡선을 1024개 점으로 샘플링해 x, y, z 각 성분을 푸리에 분해합니다(최대 |k| = 300).
- k번째 조화 성분 `A cos kt + B sin kt`는 공간 속의 타원입니다. 이 타원을 같은 평면 위에서 반대 방향으로 도는 원 두 개(+k, −k)로 나눕니다.
- 원을 반지름이 큰 순서로 이어 붙이고, 끝점이 그리는 자취가 근사 곡선이 됩니다.

## 모양
- 삼잎 매듭, 토러스 매듭, 테니스공 곡선, 3D 별
- 글자: 입력한 글을 구, 원기둥 또는 물결 면에 감습니다.
- 인물 실루엣, 업로드한 이미지의 윤곽선

## 조작
| 조작 | 동작 |
|---|---|
| 아래 막대의 N 슬라이더, ← → | 원의 개수 바꾸기 |
| 자동으로 늘리기 | N = 1부터 끝까지 차례로 늘리기 |
| Space | 멈춤 / 다시 돌기 |
| ● 녹화, R | 화면 녹화 시작 / 정지 |
| 🎬 과정 녹화 | N = 1부터 끝까지 늘리는 과정을 녹화하고 자동으로 멈춤 |
| 마우스 끌기 / 휠 | 시점 돌리기 / 확대·축소 |

## 화면 녹화
- 해상도는 화면 그대로, 1080p, 4K 중에서 고릅니다. 4K는 녹화하는 동안만 렌더 해상도를 높입니다.
- "녹화에 정보 표시"를 켜면 영상에 제목, 모양 이름, N, |k|, 오차가 함께 찍힙니다.
- 브라우저가 지원하면 MP4로, 아니면 WebM으로 `fourier-3d-YYYYMMDD-HHMMSS.mp4` 이름으로 저장됩니다.
- 최신 Chrome 또는 Edge를 권장합니다.
